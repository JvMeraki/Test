Sobre nosotros

Como participante del curso de CET - TIC Desarrollo Web Front-End con HTML, CSS y JavaScript, el objetivo es presentar el primer taller, el cual consiste en realizar la semántica en HTML para una cafetería.

Esto ha sido realizado el día 10 de septiembre, transcurridas las 12:00 horas del medio día, para más información consultar las especificaciones propuestas por el docente. Jhonatan Alarcon

PROYECTO WEB

Diseño HTML de un Sitio Web para Cafetería

Aplica todos los conceptos aprendidos para crear un sitio web semánticamente correcto para una cafetería local, incluyendo menú, ubicación, horarios y galería.

ESPECIFICACIONES

  • Header con logo/nombre y navegación principal
  • Sección de bienvenida o "Acerca de Nosotros"
  • Sección detallada del Menú (bebidas, comidas, postres)
  • Footer con copyright, ubicación y contacto
  • Uso correcto de <header>, <main>, <section> y <footer>
  • Código válido según el estándar W3C
